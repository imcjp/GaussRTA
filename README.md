# GaussRTA
 MATLAB and C++ implementations of a hybrid algorithm—featuring the Reciprocal-Argument Transformation Algorithm (RTA)—for rapid, robust, and accurate evaluation of the zero-balanced Gauss hypergeometric function $\Psi(x,y) = {}_2F_1(1, x; 1+x; -y)$. Designed for wireless network analysis and large-scale scientific computations.
